这个项目是基于太阳神三国杀国战2.3.43版本，个人开发的扩展包，并进行了一定的平衡性调整。

若技能描述与官方不符，以技能描述为准；若技能描述与游戏中表现不同，以游戏表现为准。

扩展包包括：

extension:

canghai.lua。沧海包中的部分武将；

qunlanghuanding.lua。群狼环鼎中版本不同的部分武将；

jin.lua。各个途径的晋势力武将，包括但不限于紫气东来、紫印金绶、应变等；

xianxia.lua。国战线下扩展包；

guojifu.lua。国际服的部分武将；

hanjin.lua。紫乔汉晋的部分武将，未完成测试；

jiangshanrugu.lua。江山如故中的部分武将；

junba.lua。军争身份局中的部分武将；

shenhua.lua。部分神将；

sixiangfengyin.lua。四象封印的部分武将；

xcx.lua。小程序中的部分武将；

hero.lua。英雄杀中的武将，以小程序版为主，少量为端游版，少量为小程序和端游糅合版；

equip.lua。个人根据知识储备中的各种来源，包括但不限于英雄杀、宝可梦等，结合三国杀的游戏机制，设计的武器、防具等装备；

pokemon.lua。宝可梦包。个人根据宝可梦特性/技能，结合三国杀的游戏机制，设计的技能。


testToFix:

xiliang.lua。西凉包bug修复版；

1_test.lua。国典武将平衡性调整；

canghaiz.lua。沧海中的部分武将；

xianxia_x.lua。国战线下扩展包；

secLord.lua。二代君扩展包；

testToFix文件夹下的扩展包几乎都实现了AI，可以直接使用。extension文件夹下的扩展包建议优先使用canghai.lua, xianxia.lua，其他根据个人兴趣可以尝试。
